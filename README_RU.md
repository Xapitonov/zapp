## О проекте

Zapp является частью MediathekView и предоставляет быстрый доступ ко многим немецким общественным телеканалам. Смотрите ARD, ZDF и другие каналы в прямом эфире или из медиатеки.

<b>Функции:</b>
<ul>
	<li>Клиент MediathekView для Android</li>
	<li>Прямые трансляции более 30 каналов</li>
	<li>Адаптивный стриминг — подстраивается под скорость вашего интернет-соединения</li>
	<li>Быстрая смена каналов</li>
	<li>Актуальная информация о программах</li>
	<li>Ярлыки каналов для новых версий Android</li>
	<li>Передачи почти из 20 медиатек для просмотра</li>
	<li>Удобный поиск передач в медиатеке</li>
	<li>Возможность включения субтитров для некоторых передач из медиатеки</li>
	<li>Функция «Поделиться» для видео из прямого эфира и медиатеки</li>
	<li>Воспроизведение в фоне</li>
</ul>

**Внимание:** Если вы используете Zapp за пределами Германии, некоторые каналы (например, ZDF) могут быть заблокированы.

## Переводы

Zapp разрабатывается на немецком языке, но может быть переведён на другие языки через [Transifex](https://www.transifex.com/none-581/zapp-android-app/). Предложения по новым языкам и помощь в переводе приветствуются!
