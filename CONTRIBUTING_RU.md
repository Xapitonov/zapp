# Как сделать вклад в проект

## Как открыть issue

Если вы нашли ошибку, укажите версию приложения, модель телефона или планшета и версию Android. Это поможет быстрее найти и исправить проблему.

## Как добавить / изменить / исправить код

1. Если вы планируете значительные изменения в коде, сначала создайте issue. Это позволит обсудить, как и для какой версии лучше решить вашу задачу. Для мелких правок, например опечаток, создавать issue не обязательно. Не стесняйтесь спрашивать, если у вас есть вопросы по внесению изменений в Zapp.

2. [Создайте форк](https://help.github.com/articles/fork-a-repo/) репозитория Zapp на GitHub, так как у вас нет прав на запись в оригинальный репозиторий.

3. Создайте ветку для вашей функции или исправления. Ознакомьтесь с [рекомендациями по созданию pull request](https://stackoverflow.com/questions/14680711/how-to-do-a-github-pull-request#14681796).

4. Внесите изменения в код. Используйте [правильные сообщения коммитов](http://chris.beams.io/posts/git-commit/). При сомнениях следуйте [гайдлайнам по стилю кода](https://github.com/ribot/android-guidelines/blob/master/project_and_code_guidelines.md) (за исключением префиксов для переменных и отступов пробелами).

5. Проверьте изменения на реальном устройстве или эмуляторе. Если добавляли канал, запустите тест `JsonChannelListTest`.

6. Исправьте ошибки lint. Запустите `Analyze > Inspect Code > Whole project` и убедитесь, что нет ошибок и предупреждений. Отключайте предупреждения только если уверены в правильности.

7. [Создайте pull request](https://help.github.com/articles/creating-a-pull-request/) на GitHub.

## Как собрать проект

Zapp — это Android-проект, собираемый в Android Studio. Для сборки установите последнюю версию [Android Studio](https://developer.android.com/studio/index.html) с Android SDK.

После установки выберите `File > New > Project from Version Control > GitHub`. Введите свои учётные данные. Затем укажите URL репозитория вашего форка (https://github.com/[yourname]/zapp) и папку для сохранения проекта.

Теперь вы можете собирать Zapp, запускать его на устройстве и выполнять другие операции в Android Studio.

## Как добавить новый канал

1. Отредактируйте файл [channels.json](app/src/main/res/raw/channels.json) — добавьте ваш канал. Правила:
   - `id` должен содержать только строчные латинские буквы (без умлаутов), цифры и подчёркивания
   - `id` должен быть уникальным
   - длинное `name` может содержать мягкие переносы для улучшения переноса слов
   - `stream_url` должен быть полным URL к m3u8-манифесту (f4m не поддерживается)
   - `logo_name` должен начинаться с `channel_logo_`
   - определяйте `subtitle` только если существует несколько каналов с одинаковым именем/логотипом
   - `color` должен быть самым тёмным из ярких цветов логотипа

2. Запустите тест `JsonChannelListTest` и убедитесь, что все тесты пройдены.

3. Проверьте изменения на реальном устройстве (у эмуляторов могут быть проблемы с воспроизведением видео).
